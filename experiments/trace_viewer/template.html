Cost is not comparable across the direct and governed arms. C1–C3 report a provider-billed figure per attempt. Omni's job API exposes none, and the harness pass that brackets Omni's AI credit counter around each attempt postdates every run in this frame, so C4 and C5 carry no measured cost. What covers them is the account credit total for the billing period divided across the Omni-routed attempts on disk: @@CREDIT_PER@@ per governed attempt, @@CREDIT_MAX@@ as an upper bound. That is an arm-level estimate from a counter with no per-job attribution, so it is the same figure on every governed row and cannot separate a cheap attempt from an expensive one.
